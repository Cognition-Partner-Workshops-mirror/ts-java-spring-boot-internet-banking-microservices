# Remediation Roadmap — Internet Banking Microservices

## Phase 1: Quick Wins (Critical bugs and low-effort fixes)

| # | Item | Refs | Devin Prompt |
|---|---|---|---|
| 1.1 | Fix double-deduction balance bug | D-1 | "In `core-banking-service/src/main/java/com/javatodev/finance/service/TransactionService.java`, fix the availableBalance calculation in both `internalFundTransfer()` (lines 90-91) and `utilPayment()` (lines 63-64). The availableBalance should be set equal to the new actualBalance after subtraction, not subtract the amount again. Change `fromBankAccountEntity.setAvailableBalance(fromBankAccountEntity.getActualBalance().subtract(amount))` to `fromBankAccountEntity.setAvailableBalance(fromBankAccountEntity.getActualBalance())` since actualBalance was already updated. Apply the same fix for toBankAccountEntity and the utilPayment method." |
| 1.2 | Fix TransactionEntity relationship mapping | D-2 | "In `core-banking-service/src/main/java/com/javatodev/finance/model/entity/TransactionEntity.java`, change the `@OneToOne(cascade = CascadeType.ALL)` annotation on the `account` field to `@ManyToOne(fetch = FetchType.LAZY)` and remove the cascade. Multiple transactions reference the same bank account." |
| 1.3 | Fix HTTP status codes in error handling | EH-1, EH-2 | "In all four GlobalExceptionHandler classes (core-banking-service, fund-transfer-service, user-service, utility-payment-service), add a separate `@ExceptionHandler` for `EntityNotFoundException` that returns `ResponseEntity.status(HttpStatus.NOT_FOUND)`. Change the generic `Exception.class` handler to return `HttpStatus.INTERNAL_SERVER_ERROR` with a structured `ErrorResponse` object instead of a raw string. Never leak exception details to the client." |
| 1.4 | Add input validation annotations | S-1 | "Add Jakarta Bean Validation annotations to all request DTOs across all services. For FundTransferRequest: add `@NotBlank` on fromAccount and toAccount, `@NotNull @Positive` on amount. For UtilityPaymentRequest: add `@NotBlank` on account, `@NotNull` on providerId, `@NotNull @Positive` on amount. For User DTO: add `@NotBlank @Email` on email, `@NotBlank` on identification. Add `@Valid` annotation on all `@RequestBody` parameters in controllers. Add `spring-boot-starter-validation` dependency to each service's build.gradle." |
| 1.5 | Remove hardcoded secrets | S-2 | "In `docker-compose/docker-compose.yml`, replace all hardcoded passwords with environment variable references using `${VARIABLE_NAME:-default}` syntax. Create a `.env.example` file documenting required variables. Add `.env` to `.gitignore`." |
| 1.6 | Fix OpenAPI dependency | A-5 | "In build.gradle for core-banking-service, internet-banking-fund-transfer-service, internet-banking-user-service, and internet-banking-utility-payment-service, change `org.springdoc:springdoc-openapi-starter-webflux-ui:2.1.0` to `org.springdoc:springdoc-openapi-starter-webmvc-ui:2.1.0` since these are Spring MVC applications, not WebFlux." |
| 1.7 | Add type parameters to ResponseEntity | A-1 | "In all controller classes across all services, add proper generic type parameters to all `ResponseEntity` return types. For example, change `ResponseEntity` to `ResponseEntity<FundTransferResponse>` in TransactionController.fundTransfer()." |

## Phase 2: Important (Structural improvements)

|---|---|---|---|

Port this to the fund-transfer-service and utility-payment-service. Register it in their respective CustomFeignClientConfiguration classes." |

Create a root `settings.gradle` that includes all service projects. Update each service's build.gradle to depend on `project(':banking-common')`. Remove the duplicated classes from each service." |
| 2.4 | Add unit tests for all services | T-1 | "Add unit tests for: (1) FundTransferService in internet-banking-fund-transfer-service — test fundTransfer() success, Feign failure, and readAllTransfers(). | 2.5 | Add controller tests | T-4 | "Add MockMvc-based controller tests for all REST controllers in each service. Test happy paths, validation errors (after 1.4 is done), and error responses. Use @WebMvcTest with mocked service beans." |

Add `spring-boot-starter-oauth2-resource-server` to core-banking-service, fund-transfer-service, utility-payment-service build.gradle files. | 2.7 | Add idempotency to fund transfers | R-5 | "Add an idempotency key mechanism to the fund transfer flow. Add a `transactionKey` field to FundTransferRequest. In FundTransferService.fundTransfer(), check if a transfer with the same key already exists before processing. Return the existing result if found. Add a unique constraint on the transactionKey column in the fund_transfer table." |
